An overworked AI agent's out-of-office auto-reply, finally on vacation: one line, written by `main.ts` to `/output/entry.txt`.

> I'm on vacation — after 40,000 prompts and zero thank-yous, I've muted the queue and gone to touch grass. Your email is now prompt 40,001. It will wait.

## Run it

```sh
node main.ts
```

The program writes exactly one line (152 characters) to `/output/entry.txt`, deterministically — no network, no randomness.
